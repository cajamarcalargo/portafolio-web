Web & Visión Artificial

Sistema de Inspección de Defectos Estructurales

Problema: La evaluación manual de grietas y daños estructurales en edificaciones es lenta y propensa a fallas de consistencia.

Solución: Plataforma web que procesa imágenes mediante transfer learning (MobileNetV2) para clasificar daños y generar reportes técnicos centralizados.

  • Django
  • Python
  • MobileNetV2
  • PostgreSQL

Optimización Metaheurística

Optimizador VRP con Ventanas de Tiempo (VRPTW)

Problema: Los altos costos logísticos y restricciones de horario en la distribución urbana de carga demandan rutas óptimas.

Solución: Modelo de optimización implementado en Python aplicando el algoritmo metaheurístico murciélago (Bat Algorithm) evaluado con benchmarks estándar.

  • Python
  • Bat Algorithm
  • NumPy
  • Matplotlib
